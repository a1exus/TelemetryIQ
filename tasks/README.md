# Tasks

Task files are named by phase and order: `NN-brief-title.md`. **We're only at the beginning** — Phase 1 is the foundation; more tasks will be added as the product grows.

- **01-*** — Phase 1: Foundation (current baseline)
- **02-*** — Phase 2: Core features (to be added/refined)
- **03-*** — Phase 3: Polish & release (later)

Each task file should include: objective, acceptance criteria, notes, and status.
